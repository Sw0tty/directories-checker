## Getting Started
### Dev

1. Clone the repo
   ```sh
   git clone https://github.com/Sw0tty/directories-checker.git
   ```
2. Install NPM packages
   ```sh
   npm install --allow-git=all
   ```
3. Run project
   ```sh
   npm run start
   ```
